STM32-Cleanroom-Monitor
Scope (Version 1)



This project currently implements a bare-metal environmental monitor on STM32F411RE:

\- BME280 sensor over I2C

\- Optional PMS5003 over UART

\- Local alarms via LEDs/buzzer

\- Debug logging over UART to PC



Wi‑Fi, MQTT and dashboard (Version 2) are out of scope for now.
